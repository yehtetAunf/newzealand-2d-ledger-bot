# newzealand-2d-ledger-bot
## v4.2.0 — Admin မြန်မာ Menu (Phase 1)

- Admin Private Chat `/start` တွင် မြန်မာ Reply Keyboard ပေါ်မည်။
- ပုံမှန် User နှင့် Group Chat များတွင် Admin Keyboard မပေါ်ပါ။
- User, Group, Ledger နှင့် Sales လုပ်ဆောင်ချက်များကို ခလုတ်ဖြင့် ဖွင့်နိုင်သည်။
- Approve/Ban/Unban အတွက် ယခု Phase တွင် အသုံးပြုပုံကို ခလုတ်နှိပ်ပြီး ရယူနိုင်သည်။
- ID မရိုက်ဘဲ ရွေးချယ်နိုင်သည့် Inline Button စနစ်ကို နောက် Phase တွင် ထည့်နိုင်သည်။
